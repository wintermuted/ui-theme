Layout

Page-level structural primitives. App shell wraps content in a centered max-width column. The two-column sidebar layout pins a narrow filter or navigation column beside a main content area, collapsing to stacked on mobile. The classic left-sidebar docs layout remains a valid treatment; the horizontal top-nav variant below extends it.

Source file: styles/components/layout.css

Docs Extension — Horizontal Top Nav

This layout treatment adds a sticky, horizontally scrollable top navigation bar inspired by modern developer docs. It is designed to complement, not replace, the existing sidebar layout.

The top bar surfaces key component entries for faster lateral movement (Typography, Cards, Buttons, Forms, Feedback, Data Display, Gallery, Navigation, Modal, Layout) while the sidebar continues to provide full sectioned navigation.

App Shell — .app-shell

Centered, max-width (960 px) page wrapper. Apply to the outermost page container. Provides 1 rem padding on all sides so content never touches the viewport edge on small screens.

The inner .app-header holds three horizontal zones: brand column (.app-brand), navigation row (.app-nav), and actions (.app-header-actions). At ≤768 px these collapse to a vertical stack.

Two-Column Sidebar Layout — .sidebar-layout

Flex row with a fixed 220 px left column (.sidebar-layout-aside) and a fluid main panel (.sidebar-layout-main). A right border on the aside acts as the column divider. Collapses to vertical stacking on viewports ≤768 px.

Use .sidebar-section-title to label filter or nav groups within the aside.

Responsive Behaviour

Viewport App Header Sidebar Layout
>768 px Single row: brand / nav / actions side by side Two columns — aside left, main right
≤768 px Stacked column: brand → nav → actions Stacked: aside on top, main below; aside border becomes bottom border

Entry Header — .entry-header

Two-column flex row: primary label on the left, secondary metadata (date, status) on the right. Wraps gracefully on narrow viewports. Use for timeline entries, work history rows, list items with a date, or any scan-first two-column label + meta pattern.

Content Grid — .content-grid

Responsive auto-fill grid for equal-width content tiles — skill categories, feature blocks, or grouped metadata. Each cell is at least 220 px and expands to fill available space without a media query.

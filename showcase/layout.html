Structure

Layout

Page-level structural primitives. App shell wraps content in a centered max-width column. The two-column sidebar layout pins a narrow filter or navigation column beside a main content area, collapsing to stacked on mobile.

Source file: styles/components/layout.css

App Shell — .app-shell

Centered, max-width (960 px) page wrapper. Apply to the outermost page container. Provides 1 rem padding on all sides so content never touches the viewport edge on small screens.

The inner .app-header holds three horizontal zones: brand column (.app-brand), navigation row (.app-nav), and actions (.app-header-actions). At ≤768 px these collapse to a vertical stack.

Two-Column Sidebar Layout — .sidebar-layout

Flex row with a fixed 220 px left column (.sidebar-layout-aside) and a fluid main panel (.sidebar-layout-main). A right border on the aside acts as the column divider. Collapses to vertical stacking on viewports ≤768 px.

Use .sidebar-section-title to label filter or nav groups within the aside.

Responsive Behaviour

Viewport App Header Sidebar Layout
>768 px Single row: brand / nav / actions side by side Two columns — aside left, main right
≤768 px Stacked column: brand → nav → actions Stacked: aside on top, main below; aside border becomes bottom border

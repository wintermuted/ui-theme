Inputs and Actions

Slider

Custom-styled <input type="range"> with accent track, thumb, and tick label support. Uses -webkit- and -moz- prefixes for cross-browser consistency.

Source file: styles/components/slider.css

Slider track/thumb colors use the same OpenAI-style control tokens as toggles for visual consistency. Active track and thumb ring use #0285ff.

Default

Apply .wm-slider to any <input type="range">.

<input type="range" class="wm-slider" min="1" max="10" value="5" />

With Label Row

Wrap in .wm-slider-row with a .wm-slider-label and optional .wm-slider-value to show the current value inline.

Generation Speed 5 
<div class="wm-slider-row">
  <span class="wm-slider-label">Generation Speed</span>
  <span class="wm-slider-value" id="val">5</span>
</div>
<input type="range" class="wm-slider" min="1" max="10" value="5"
  oninput="document.getElementById('val').textContent = this.value" />

With Tick Labels

Add a .wm-slider-ticks row of .wm-slider-tick spans below the input to indicate key values. These are decorative — use step on the input for snapping.

Zoom 50
0 25 50 75 100 
<input type="range" class="wm-slider" min="0" max="100" value="50" step="10" />
<div class="wm-slider-ticks">
  <span class="wm-slider-tick">0</span>
  <span class="wm-slider-tick">25</span>
  <span class="wm-slider-tick">50</span>
  <span class="wm-slider-tick">75</span>
  <span class="wm-slider-tick">100</span>
</div>

Disabled State

Apply the native disabled attribute. Opacity drops and thumb cursor changes to not-allowed.

Speed (locked) 3 
<input type="range" class="wm-slider" min="1" max="10" value="3" disabled />

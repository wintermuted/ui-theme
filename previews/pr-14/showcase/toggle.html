Inputs and Actions

Toggle Switch

CSS-only pill toggle switch built on a visually-hidden <input type="checkbox">. Fully accessible — keyboard navigable, screen-reader labelled, and focus-ring compliant.

Source file: styles/components/toggle.css

Toggle colors use the shared control tokens for OpenAI-style contrast: on = #0285ff, off = neutral gray, thumb = light neutral.

Default

Unchecked by default. The track changes to accent blue when checked.

<label class="wm-toggle">
  <input type="checkbox" class="wm-toggle-input" />
  <span class="wm-toggle-track"><span class="wm-toggle-thumb"></span></span>
  <span class="wm-toggle-label">Offline mode</span>
</label>

With Description

Add a <p class="wm-toggle-description"> sibling below the label to surface supplementary help text aligned under the label.

Live cells with 2 or 3 neighbours survive to the next generation.

Live cells with more than 3 neighbours die from overpopulation.

<div>
  <label class="wm-toggle">
    <input type="checkbox" class="wm-toggle-input" checked />
    <span class="wm-toggle-track"><span class="wm-toggle-thumb"></span></span>
    <span class="wm-toggle-label">Enable survival rule</span>
  </label>
  <p class="wm-toggle-description">Live cells with 2 or 3 neighbours survive.</p>
</div>

Stacked Group

Wrap multiple toggles in .wm-toggle-list for consistent vertical spacing. Ideal for settings panels.

2 or 3 live neighbours → survives.

Dead cell with exactly 3 live neighbours → becomes alive.

More than 3 live neighbours → dies.

<div class="wm-toggle-list">
  <div>
    <label class="wm-toggle">
      <input type="checkbox" class="wm-toggle-input" checked />
      <span class="wm-toggle-track"><span class="wm-toggle-thumb"></span></span>
      <span class="wm-toggle-label">Survival rule</span>
    </label>
    <p class="wm-toggle-description">2 or 3 live neighbours → survives.</p>
  </div>
  <!-- repeat for each toggle -->
</div>

Disabled State

Apply disabled on the <input>. The :has() selector reduces the whole label to 50% opacity and sets cursor: not-allowed.

<label class="wm-toggle">
  <input type="checkbox" class="wm-toggle-input" disabled />
  <span class="wm-toggle-track"><span class="wm-toggle-thumb"></span></span>
  <span class="wm-toggle-label">Disabled toggle</span>
</label>

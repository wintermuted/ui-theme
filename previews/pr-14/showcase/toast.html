Status and Messaging

Toast

Fixed bottom-center notification bar. Show and hide by toggling .wm-toast-visible in JavaScript. Four tonal variants: success, danger, warning, and info. Includes an optional dismiss button.

Source file: styles/components/toast.css

Tonal Variants

Each variant uses semantic color tokens. The static examples below are positioned inline (not fixed) so they display in the document flow.

.wm-toast-success — Pattern saved.
.wm-toast-danger — Could not load pattern.
.wm-toast-warning — Unsaved changes may be lost.
.wm-toast-info — URL copied to clipboard.

Usage Pattern

Render the toast in the DOM at mount time. Show it by adding .wm-toast-visible; hide it by adding .wm-toast-hiding, waiting for the transition, then removing both classes. Auto-dismiss after a timeout via setTimeout. 

<div id="toast" class="wm-toast wm-toast-success" role="status" aria-live="polite">
  Operation complete.
  <button class="wm-toast-dismiss" type="button" aria-label="Dismiss">&#x2715;</button>
</div>
function showToast(id, durationMs = 3000) {
  const el = document.getElementById(id);
  el.classList.add('wm-toast-visible');
  setTimeout(() => {
    el.classList.add('wm-toast-hiding');
    setTimeout(() => el.classList.remove('wm-toast-visible', 'wm-toast-hiding'), 250);
  }, durationMs);
}

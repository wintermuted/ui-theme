Inputs and Actions

Toggle Group

Exclusive segmented control — pick one option from a small set. Distinct from .tab-bar (page navigation) in that it drives a value selection, not a view switch. Supports horizontal, vertical, and full-width layouts.

Source file: styles/components/toggle-group.css

Horizontal (Default)

Wrap buttons in .wm-toggle-group. Mark the selected option with .wm-toggle-group-btn-active or aria-pressed="true". 

<div class="wm-toggle-group" role="group" aria-label="View mode">
  <button class="wm-toggle-group-btn wm-toggle-group-btn-active" type="button">Day</button>
  <button class="wm-toggle-group-btn" type="button">Week</button>
  <button class="wm-toggle-group-btn" type="button">Month</button>
</div>

Vertical Full-Width

Add .wm-toggle-group-vertical and .wm-toggle-group-full for a stacked full-width palette or option list. Ideal for sidebar controls. 

<div class="wm-toggle-group wm-toggle-group-vertical wm-toggle-group-full"
     role="group" aria-label="Color palette">
  <button class="wm-toggle-group-btn wm-toggle-group-btn-active" type="button">
    <span class="wm-toggle-group-swatch" style="background: #00ff41;"></span>
    Matrix
  </button>
  <!-- repeat -->
</div>

Disabled State

Apply disabled to individual buttons. Disabled items are 50% opaque with a not-allowed cursor.

<div class="wm-toggle-group" role="group">
  <button class="wm-toggle-group-btn wm-toggle-group-btn-active" type="button">PNG</button>
  <button class="wm-toggle-group-btn" type="button">SVG</button>
  <button class="wm-toggle-group-btn" type="button" disabled>PDF</button>
</div>

Toggle Group vs Tab Bar

Use .wm-toggle-group when selecting a value (color palette, speed preset, export format). Use .tab-bar when switching between views or content panels. The visual style is similar; the semantic intent differs.

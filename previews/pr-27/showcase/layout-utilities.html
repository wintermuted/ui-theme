Layout Utilities — Opt-in Helpers

Optional utility classes that extend layout primitives without forcing one-size-fits-all behavior. Use these for app-specific shells where nav density, rail width, divider treatment, or sticky controls differ from docs defaults.

Source file: styles/components/layout.css

Available Utilities

Utility Purpose
.wm-app-nav-nowrap Keeps nav links on one row and enables horizontal scrolling instead of wrapping.
--wm-sidebar-aside-width Sets the base aside width for .wm-sidebar-layout-aside (default: 220px).
--wm-sidebar-aside-min-width Sets a floor for rail width when flex sizing would otherwise shrink too far.
--wm-sidebar-aside-max-width Sets a ceiling for rail width when parent layouts provide extra space.
.wm-sidebar-layout-stretch Makes the sidebar layout consume available vertical space inside app shells.
.wm-sidebar-layout-aside-no-divider Removes the vertical divider and right padding from the aside rail.
.wm-sticky-bottom Pins a toolbar or control region to the bottom of its scrolling container.

Game Workspace Recipe

This is the exact pattern used by the Game of Life app shell: stretched two-column workspace, no rail divider, sticky control dock, and tokenized rail sizing. 

<section
  className="App wm-sidebar-layout wm-sidebar-layout-stretch"
  style={{
    ['--wm-sidebar-aside-width' as string]: '390px',
    ['--wm-sidebar-aside-min-width' as string]: '350px',
  }}
>
  <main className="left-column wm-sidebar-layout-main">
    {/* grid + content */}
    <div className="game-controls-bar wm-sticky-bottom">
      {/* controls */}
    </div>
  </main>

  <aside className="right-column wm-sidebar-layout-aside wm-sidebar-layout-aside-no-divider">
    {/* cards */}
  </aside>
</section>

When to Use

  • Use .wm-app-nav-nowrap when app nav labels are numerous and should not collapse into multiple rows.
  • Use --wm-sidebar-aside-width plus --wm-sidebar-aside-min-width when a rail needs more than quick filters (e.g., pattern browser, diagnostics, details).
  • Use .wm-sidebar-layout-stretch when the workspace should fill available vertical space.
  • Use .wm-sidebar-layout-aside-no-divider when the app surface intentionally avoids split lines.
  • Use .wm-sticky-bottom for control docks that should remain available during vertical scrolling.
